# ManeComb Next

Reingeniería full-stack de ManeComb basada en Next.js App Router, Node.js runtime, Socket.IO, MongoDB y Redis.

> Este repositorio se está construyendo conforme al Plan Maestro de ManeComb: una sola base de código web/full-stack, dominios separados por Route Groups y soporte opcional de Android nativo para mantener telemetría GPS con el dispositivo bloqueado.

La implementación activa vive en la rama de arquitectura y será integrada mediante PR.
